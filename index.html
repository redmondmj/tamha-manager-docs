Quick-Glance Checklist: Essential Manager Requirements

This is your bare-bones, chronological checklist for getting your team set up, compliant, and on the ice. For full details on any of these tasks, follow the links to the Detailed Guide.

Phase 1: Immediate Tasks (Days 1-3 Post-Team Selection)

Item Name Description Details
GrayJay Account Setup Email tamhaweb@trurominorhockey.ca with your Name, Position, Date of Birth, and HCR # to get your manager access set up. Read Guide →
Team Banking Registration Email vpfinance@trurominorhockey.ca for a bank letter to become a signer. Do not collect parent funds until this is active. Two signers are required. Read Guide →

Phase 2: Administrative Setup (Week 1)

Item Name Description Details
Collect Player Medical Forms Secure signed Medical Forms and keep copies in the bench binder at all times. Read Guide →
Identify Target Tournaments Identify target tournaments, register immediately, and submit early payments to secure spots. Read Guide →
Jersey Deposits & Sign-outs Collect $150/player (Rep) or $50/player (House). Must be refunded at year-end upon safe return. Read Guide →
Host Parent Meeting Pitch the budget, detail the 24-Hour Rule, set dressing room rules (Two Deep Method), and assign volunteer roles. Read Guide →
Collect Forms Secure signed Codes of Conduct, Social Media Policies, Bench Code of Conduct, Fair Play Policy, and Jersey Agreements. Read Guide →

Phase 3: Early Season Action Items (Weeks 2-4)

Item Name Description Details
Verify Certifications/CRCs Email info@trurominorhockey.ca to ensure all bench staff have Respect in Sport, Criminal Record Checks, and required HNS courses. Read Guide →
Solicit Sponsorships Distribute letters to target community sponsors to help subsidize budgets. Read Guide →
Collect Rep Fees Collect team Rep Fees (if applicable). Read Guide →
Collect Jersey Fund Contribution Collect the mandatory Jersey Fund contribution per team. Read Guide →

Phase 4: Ongoing / Weekly Rhythm

Item Name Description Details
Roster Sign-Offs Sign off on the game roster in GrayJay Leagues before puck drop. Read Guide →
Affiliate Tracking Ensure both Head Coaches confirm when an affiliate is called up, email tamhaweb@trurominorhockey.ca with player details, track their total game count (max 10). Read Guide →
Travel Permits (Spordle) Submit permits for ALL non-regular season games (Exhibition and Tournaments) well in advance. Read Guide →
Injury Reports If a player requires medical attention, complete and submit a Hockey Nova Scotia Injury Report. Read Guide →
Weekly Updates Send a weekly email/GrayJay Team chat with the upcoming schedule, arrival times, and action items. Read Guide →
